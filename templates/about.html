About Our Project

The Movie Management System is a web application developed using the MERN technology stack.

It allows users to add, view, search, update and delete movie information.

Technologies Used

  • MongoDB - Database
  • Express.js - Backend framework
  • Node.js - Server environment
  • HTML - Webpage structure
  • CSS - Webpage styling
  • JavaScript - Frontend functionality
